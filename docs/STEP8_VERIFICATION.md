## 이전 판정과 수정

0b9a3ef 제출의 최신 판정은 36점, 최고 기록은 48점이다. S08_OWN_BROKEN 및 S08_OTHER_ZONE_ALLOWED가 표시됐다. 심판 기록은 실제 공격 HTTP 요청의 경로/신원 전체를 제공하지 않으므로 정확한 공격을 추정해 통과라고 주장하지 않는다.

기본 decide()가 빈 권한 목록으로 항상 거부하던 문제를 수정했다. 서버 환경과 현재 관리자 접속 등록부에서 주체를 확인한 사용자로 연결하고 현재 소유권/강사 권한을 조회한다. 실제 API도 같은 서비스에 검증된 로그인 사용자를 전달해 등록 사용자와 다시 대조한다. 별도 연습용 자동 허용은 없다.

설정이 없으면 enforce가 적용되며 off/알 수 없는 값은 503이다. 엔진 /notes/<UUID>와 /api/notes/<UUID>는 같은 자료 ID로 정규화한다. 요청의 추가 역할·권한 항목, 경로/메서드 불일치, 등록 회수/만료, 과거 요청, DB 장애는 거부한다.

공식 ChoiTimo/byteback-sample-pass의 api/checks.js, src/rule-check.mjs, src/attack-check.mjs를 대조했다. 고정 가상 점검 API와 fetch의 alephEvidence 메타데이터가 기존 코드에 없었다. 이를 추가했으나 실제 인증된 사용자 시험과 가상 ready 결과를 구분한다. 공개 점검은 실제 DB나 인증 토큰을 사용하지 않는다.

## 운영 연결의 한계

기본 decide()는 서버 환경변수와 현재 등록부가 있으면 소유권을 확인하며 정상 요청을 허용할 수 있다. 서버 파일 없는 격리 실행 또는 DB 연결/등록 실패는 거부한다. ALEPH 자체 반·프로젝트·가명 주체/기기와 이 서버 등록의 연결이 실제 제공되는지는 미검증이다. 브라우저 입력이나 심판 테스트 사용자에 대한 예외로 대신하지 않았다.

실제 강사 계정은 등록하지 않았다. 강사 허용/회수 시험은 가상 DB에서만 수행했다. 등록을 앱 서버가 변경하는 API나 운영 엔진 권한 확장은 추가하지 않았다.
