# 첫 보너스 작전 상태

공식 최신 main 2cd777b452525b95e29f12f2c76d9190a594ec23의 XDR 안내를 적용했습니다.
시험 경보는 원본 8a092740에서 가져왔으며 최신 버전과 동일합니다.

## 구현 및 재현

- read-alerts.mjs: 필요한 다섯 필드 추출 및 비밀값 패턴 제거.
- patterns.json: MITRE T1110 근거. 수치 기준은 수업용 정책이며 MITRE 권고 수치가 아닙니다.
- decide.mjs: import·파일 읽기·외부 호출 없이 독립적으로 판단합니다. 최신 심판 안내는 Jev 호출 대신 자체 확신도를 요구합니다.
- deny-rules.mjs 및 enforce.mjs: 만료와 경보 근거를 가진 차단 후보, 기존 판정 유지 연결 모듈.
- alerts.log: 가상 경보의 안전한 결과만 누적 기록.

실행: node scripts/check-xdr-brute-force.mjs
공식 경보 28건: block 10, alert 9, record 9. 정상 이벤트 오차단 0건.
단일 파일 data URL 실행도 같은 결과이며 경보 ID를 바꿔도 신호 기반 판정을 유지합니다.
연결 모듈은 가상 기본 allow 판정기로 정상 허용·공격 거부·만료 뒤 허용을 확인했습니다.
기존 초기 판정기의 deny는 유지하고 본문에 위조한 출발 주소는 쓰지 않습니다.

## 운영 연결 한계

src/decider.mjs는 아직 초기 틀이고 공식 요청 계약에는 출발 IP가 없습니다.
운영 엔진의 신뢰할 수 있는 주소 전달과 등록 reasonCode가 필요하므로 실제 엔진에는 연결하지 않았습니다.
이 결과는 로컬 시험이며 운영 차단 또는 심판 통과를 증명하지 않습니다.
3·4단계 로컬 검사와 로컬 빌드는 통과했습니다. 기존 test:r5는 1단계 기대값 두 건이 남아 실패하며 이번 변경 대상이 아닙니다.
제출 칸 입력과 심판 제출은 하지 않습니다.
